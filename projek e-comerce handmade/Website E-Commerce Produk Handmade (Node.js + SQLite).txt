🌐 Rencana Lengkap Website E-Commerce Produk Handmade (Node.js + SQLite)

1. Tujuan Website 

    Menjual produk handmade (misalnya: aksesoris, tas, perhiasan, dekorasi rumah) secara online.
    Membangun merek lokal yang terpercaya dan estetik.
    Memberikan pengalaman belanja yang mudah, cepat, dan aman.
    Menjangkau wanita usia 20–40 tahun di Indonesia yang menyukai produk unik dan bernilai seni.
     

2. Target Pengguna 

    Demografi: Wanita usia 20–40 tahun.
    Karakteristik: 
        Menghargai keunikan dan keaslian produk.
        Aktif di media sosial (Instagram, TikTok, Pinterest).
        Lebih suka belanja online via smartphone.
        Peduli terhadap kualitas, desain, dan keberlanjutan.
         
    Kebutuhan: 
        Produk berkualitas tinggi.
        Proses pembayaran cepat dan aman.
        Desain yang menarik dan ramah pengguna.
        Informasi produk jelas dan transparan.
         
     

3. Bahasa dan Lokalisasi 

    Bahasa utama: Bahasa Indonesia (dengan opsi bahasa Inggris jika diperlukan).
    Format lokal:
        Harga: Rp (misalnya: Rp 125.000)
        Tanggal: DD-MM-YYYY
        Nomor telepon: +62 (dengan format lokal)
         
    Lokalisasi: Fokus pada wilayah Indonesia (dengan pengiriman lokal dan logistik lokal).
     

4. Tema & Desain 

    Gaya desain: Minimalis, feminin, dan elegan.
    Palet warna:
        Utama: #F5E8E8 (krem lembut), #E8D5D5 (merah muda pastel)
        Aksen: #8D6E63 (coklat muda), #A1887F (abu-abu lembut)
         
    Font: 
        Heading: Poppins (sans-serif modern)
        Body: Nunito atau Lato (mudah dibaca)
         
    Desain responsif: 100% mobile-first (didesain untuk layar kecil dulu).
    Fitur tambahan: 
        Dark mode (opsional)
        Animasi halus saat scroll atau klik
        Zoom gambar produk saat diperbesar

9. Database (SQLite) – Struktur Tabel

-- Tabel Produk
CREATE TABLE products (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    description TEXT,
    price REAL NOT NULL,
    stock INTEGER NOT NULL,
    category TEXT,
    image_url TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Tabel Keranjang
CREATE TABLE cart (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    product_id INTEGER,
    quantity INTEGER DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (product_id) REFERENCES products(id)
);

-- Tabel Pesanan
CREATE TABLE orders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    total_price REAL,
    status TEXT DEFAULT 'pending',
    payment_method TEXT,
    address TEXT,
    phone TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- Tabel Detail Pesanan
CREATE TABLE order_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    order_id INTEGER,
    product_id INTEGER,
    quantity INTEGER,
    price REAL,
    FOREIGN KEY (order_id) REFERENCES orders(id),
    FOREIGN KEY (product_id) REFERENCES products(id)
);

-- Tabel Pengguna
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    password TEXT NOT NULL,
    phone TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);


10. Fitur Pembayaran (Midtrans) 

    Gunakan Midtrans sebagai gateway pembayaran.
    Dukungan:
        OVO
        Dana
        Kartu kredit (Visa, Mastercard)
        Bank transfer
         
    Integrasi:
        Backend: Kirim data pesanan ke Midtrans via API
        Frontend: Redirect ke halaman pembayaran Midtrans
        Webhook: Terima notifikasi pembayaran dari Midtrans
         
     

11. Kecepatan & Performa 

    Gunakan caching untuk data produk (misalnya: Redis).
    Optimasi gambar: resize & compress sebelum upload.
    Gunakan lazy loading untuk gambar.
    Gunakan CDN (jika diperlukan) untuk gambar produk.
     

12. SEO & Pemasaran

    URL bersih: /produk/tas-kecil-handmade

🛠️ Langkah Awal untuk Memulai 
     
	Siapkan lingkungan pengembangan: 

npm init -y
npm install express cors body-parser sqlite3
npm install -D nodemon

 

	Buat struktur folder seperti di atas. 
 

	Buat server Express (server.js): 

const express = require('express');
const app = express();
const port = 3000;

app.use(express.json());
app.use(express.urlencoded({ extended: true }));

app.get('/', (req, res) => {
  res.send('Hello, E-Commerce Handmade!');
});

app.listen(port, () => {
  console.log(`Server running on http://localhost:${port}`);
});
 

	Integrasi Midtrans: 

    Daftar akun di Midtrans 
    Gunakan SDK Node.js: npm install midtrans-client
     

	Buat API untuk produk: 

    GET /api/products → ambil semua produk
    GET /api/products/:id → detail produk
    POST /api/cart → tambah ke keranjang
     

	Buat frontend (React): 

npx create-react-app frontend
npm install react-router-dom axios

	Deploy ke Vercel + Railway: 

    Frontend: Vercel
    Backend: Railway (dengan database SQLite)

📌 Catatan Penting 

    SQLite cocok untuk skala kecil (prototipe atau startup kecil).
    Jika nanti traffic naik, ganti ke PostgreSQL atau MongoDB.
    Untuk keamanan, gunakan HTTPS (via Vercel atau Let's Encrypt).
    Gunakan env variables untuk menyimpan API key (Midtrans, DB, dll).
